# Weekly Digest

Use this playbook to produce a weekly product analytics summary.

## Goal

Give the team a concise view of what changed, what looks healthy, and what needs attention.

## Inputs

| Input | Description |
| --- | --- |
| Date range | Last completed calendar week. |
| Core events | Signups, activations, purchases, upgrades, cancellations. |
| Segments | New users, returning users, plans, and acquisition source. |

## Steps

1. Compare total active users against the previous week.
2. Compare signup and activation counts against the previous week.
3. List the top growing and shrinking events.
4. Check funnel drop-offs for signup to activation.
5. Summarize notable segments.

## Output

```md
## Weekly Digest

- Active users:
- New signups:
- Activation rate:
- Biggest increase:
- Biggest drop:
- Recommended follow-up:
```
