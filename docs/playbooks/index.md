# Playbooks

Playbooks are operational recipes. Each one explains the goal, the data required, the analysis steps, and the output an operator or agent should produce.

Use playbooks when you want repeatable product analytics work instead of one-off dashboard clicking.

## Available playbooks

| Playbook | Use it for |
| --- | --- |
| [Weekly Digest](/docs/playbooks/weekly-digest) | Send a concise summary of top product metrics every week. |
| [Launch Review](/docs/playbooks/launch-review) | Compare adoption and retention before and after a release. |

## Playbook shape

Every playbook should include:

1. Goal
2. Inputs
3. Query or analysis steps
4. Output format
5. Escalation criteria
